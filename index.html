Pendahuluan & Konfigurasi Proyek

Langkah awal berfokus pada penyiapan proyek kosong (Empty Project) serta standarisasi rasio aspek layar agar antarmuka tidak terpotong saat dijalankan.

Tahapan Konfigurasi di GDevelop 5:

  1. Buka GDevelop 5 > klik Create a new project > pilih Empty project.
  2. Tentukan direktori penyimpanan pada folder kerja komputer Anda.
  3. Buka menu Game Settings (ikon roda gigi di bilah kiri) > pilih menu Properties.
  4. Atur parameter resolusi dasar proyek:
    • Game resolution width: 1280 px
    • Game resolution height: 720 px
    • Game resolution resize mode: Ganti menjadi Extend width or height to fill screen.
💡 Catatan Teknis: Opsi Extend width or height to fill screen menjaga letak teks skor di sudut kanan atas layar tetap utuh dan presisi pada berbagai resolusi monitor tanpa terpotong.

Pembuatan & Desain Aset 2D (Piskel)

Seluruh objek dibuat secara mandiri dengan editor piksel bawaan Piskel. Tabel berikut otomatis menyesuaikan menjadi kartu ringkas pada layar ponsel pintar.

No Nama Objek Tipe Ukuran Piksel Fungsi & Proporsi
1 player Sprite 32x32 / 32x48 px Karakter utama yang digerakkan oleh pemain di atas tanah.
2 enemy Sprite 32x32 px Musuh rintangan patroli; berukuran seimbang dengan karakter pemain.
3 coin Sprite 16x16 / 24x24 px Item koleksi poin yang melayang untuk dikumpulkan pemain.
4 ground Tiled Sprite 32x32 px (Grid) Pijakan solid; pola berulang untuk menyusun lantai panggung.
5 hazard Sprite 32x32 / 16x32 px Jebakan statis (duri/lahar) yang memicu kekalahan bila disentuh.
6 finishDoor Sprite 32x64 / 48x64 px Pintu akhir level; dibuat lebih tinggi dari tinggi karakter.
7 deadZone Sprite 32x32 px Sensor jurang di bagian bawah panggung (disembunyikan di awal).
8 leftBoundary Sprite 32x32 px Pembatas balik kiri patroli musuh (disembunyikan saat bermain).
9 rightBoundary Sprite 32x32 px Pembatas balik kanan patroli musuh (disembunyikan saat bermain).
10 scoreText Text - Menampilkan teks perolehan skor pemain (misal: "Skor : 0").
11 alertText Text - Pesan peringatan sementara jika syarat skor belum tercapai.

Penerapan Fisika & Behavior Objek

Behavior menyematkan simulasi fisika platformer ke dalam objek secara instan tanpa perlu coding matematika manual.

1. Objek Pijakan (ground)

Buka objek ground > tab Behaviors > tambahkan Platform (Type: Platform). Objek ini berfungsi sebagai alas padat yang dapat dipijak.

2. Objek Karakter Pemain (player)

Tambahkan behavior Platformer Character dan pastikan opsi Default controls: Enabled. Pemain otomatis bisa melangkah dengan tombol panah dan melompat dengan Space.

3. Objek Musuh (enemy)

Tambahkan behavior Platformer Character, lalu HILANGKAN centang Default controls (Disabled). Turunkan nilai Max speed ke 100 agar musuh tidak melaju terlalu kencang namun tetap mematuhi gravitasi.

Kecerdasan Buatan Musuh: Patroli Otomatis (Enemy AI)

Musuh berpatroli bolak-balik antara leftBoundary dan rightBoundary menggunakan variabel objek bernama arah.

Persiapan Variabel:

Buka properti objek enemy > tab Variables > buat variabel arah bertipe String dengan nilai awal "kanan".

Condition (Syarat)
At the beginning of the scene
Action (Aksi)
1. Hide leftBoundary
2. Hide rightBoundary
Event 2: Gerak Patroli ke Kanan
Condition (Syarat)
The variable arah of enemy = "kanan"
Action (Aksi)
Simulate pressing Right for enemy
Event 3: Gerak Patroli ke Kiri
Condition (Syarat)
The variable arah of enemy = "kiri"
Action (Aksi)
Simulate pressing Left for enemy
Event 4 & 5: Deteksi Tabrakan Pembatas
Condition (Syarat)
enemy is in collision with leftBoundary
Action (Aksi)
Change the variable arah of enemy: set to "kanan"
Condition (Syarat)
enemy is in collision with rightBoundary
Action (Aksi)
Change the variable arah of enemy: set to "kiri"

Mekanik Koleksi Koin & Variabel Skor Dinamis

Koin yang disentuh pemain akan dihapus, menambah variabel skor tingkat scene sebesar +50 poin, dan memperbarui teks tampilan skor.

Event Pengambilan Koin
Condition (Syarat)
player is in collision with coin
Action (Aksi)
1. Delete coin
2. Change the variable skor: add 50
3. Change the text of scoreText: set to "Skor : " + ToString(Variable(skor))
💡 Penjelasan Fungsi: Perintah ToString(Variable(skor)) mengubah nilai bilangan numerik menjadi teks agar kompatibel dicetak pada objek scoreText.

Kontrol Kamera & Pembatasan Area Layar

Kamera bergerak mengikuti karakter pemain dan berhenti secara mulus di batas tepi panggung tanpa menampilkan ruang kosong putih.

Event Pergerakan Kamera
Condition (Syarat)
(Dikosongkan - otomatis dieksekusi setiap frame)
Action (Aksi)
1. Center camera on player (layer: "Base layer")
2. Enforce camera boundaries (left: 0, top: 0, right: 2070, bottom: 720, layer: "Base layer")
✨ Keunggulan: Logika ini murni menggunakan aksi bawaan GDevelop tanpa ketergantungan pada ekstensi eksternal, sehingga stabil dan ringan untuk game edukasi sekolah.

Syarat Menang & Notifikasi Berdurasi (Object Timer)

Pintu akhir tersembunyi hingga skor mencapai minimal 100 poin. Jika pemain menyentuh pintu sebelum target skor tercapai, muncul pesan peringatan sementara selama 2 detik.

1. Kondisi Awal Layar
Condition
At the beginning of the scene
Action
1. Hide finishDoor
2. Hide alertText
2. Membuka Gerbang Pintu
Condition
The variable skor >= 100
Action
Show finishDoor
3. Pindah Level (Menang)
Condition
player is in collision with finishDoor
The variable skor >= 100
Action
Change to scene "level2"
4. Notifikasi Peringatan Timer (2 Detik)
Condition
player is in collision with finishDoor
The variable skor < 100
Action
1. Show alertText
2. Start (or reset) timer "alert" of alertText
Condition
The timer "alert" of alertText > 2 seconds
Action
Hide alertText

Antarmuka Pengguna (UI Layer) & Tata Letak

Elemen antarmuka (HUD) dipisahkan ke dalam layer khusus agar posisinya tetap statis dan tidak ikut bergeser saat kamera bergerak mengikuti pemain.

Langkah Pembuatan Layer Antarmuka:

  1. Buka panel Layer list pada scene editor GDevelop.
  2. Klik Add a layer dan beri nama UI. Posisikan di urutan teratas (di atas Base layer).
  3. Pilih objek scoreText pada panggung > ganti properti Layer menjadi UI.
  4. Tempatkan di pojok kanan atas kanvas (koordinat ideal: X: 1121, Y: 19).
  5. Pindahkan juga objek alertText ke layer UI dan letakkan di area tengah layar.

State Animasi Karakter Player

Animasi membuat karakter tampak lebih hidup dan responsif terhadap aksi input pemain.

Kelompok Animasi di Piskel:

  • Animation 0 (Idle): Karakter diam saat berdiri di atas tanah.
  • Animation 1 (Walk): Karakter berjalan (Aktifkan opsi Loop).
  • Animation 2 (Jump): Pose karakter saat berada di udara (melompat/jatuh).
Logika Pergantian Animasi
Condition (Melompat / Di Udara)
player is jumping OR player is falling
Action
Change the animation of player: set to 2
Condition (Berjalan di Tanah)
player is on floor
player is moving
Action
Change the animation of player: set to 1
Condition (Diam di Tanah)
player is on floor
player is moving (Inverted: Tidak Bergerak)
Action
Change the animation of player: set to 0
