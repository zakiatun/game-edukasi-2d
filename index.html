1

Konfigurasi Proyek & Dasar Engine

Langkah awal berfokus pada penyiapan proyek kosong (Empty Project) serta standarisasi rasio aspek layar agar antarmuka tidak terpotong saat dijalankan di PC maupun ponsel pintar.

Tahapan Konfigurasi di GDevelop 5:

  1. Buka GDevelop 5 > klik Create a new project > pilih template Empty project.
  2. Tentukan nama proyek (misal: GameEdukasi2D_Platformer) dan pilih lokasi penyimpanan di komputer Anda.
  3. Klik ikon Game Settings (ikon roda gigi di bilah kiri) > pilih menu Properties.
  4. Lakukan penyesuaian parameter tampilan:
    • Game resolution width: 1280 px
    • Game resolution height: 720 px
    • Game resolution resize mode: Ganti menjadi Extend width or height to fill screen.
    • Scale mode (Sampling): Pilih Nearest (pixelated) agar grafis piksel tetap tajam dan tidak kabur.
💡 Catatan Teknis: Opsi Extend width or height to fill screen menjaga letak teks skor di sudut kanan atas layar tetap utuh dan presisi pada berbagai rasio layar tanpa terpotong.

3

Panduan Lengkap Membuat Animasi di Piskel

Piskel adalah editor seni piksel berbasis frame-by-frame. Sebelum memprogram event logika di GDevelop, seluruh rangkaian gerak karakter harus disiapkan terlebih dahulu.

A. Perkakas Utama di Piskel:

  • Pen Tool (P): Menggambar piksel demi piksel dengan warna aktif.
  • Paint Bucket (B): Mengisi area sewarna secara instan.
  • Duplicate Frame (Ikon Kertas Ganda): Menggandakan frame aktif agar Anda tidak perlu menggambar ulang karakter dari nol pada frame berikutnya.
  • Onion Skin (Ikon Bawang): Menampilkan siluet frame sebelumnya secara transparan sebagai pemandu perubahan posisi gerak tubuh.
  • FPS Slider: Mengatur kecepatan putaran animasi (misal: 8 FPS untuk berjalan, 3 FPS untuk diam bernapas).

B. Tahap demi Tahap Membuat 3 Animasi Inti Karakter:

Animation 0: IDLE (Diam) FPS: 3 (Loop)
Tujuan: Karakter tampak bernapas lembut saat tidak bergerak.

Frame 1: Gambar pose karakter berdiri tegak dengan proporsi standar 32x32 px.
Frame 2: Klik tombol Duplicate. Gunakan alat seleksi kotak, pilih bagian kepala dan bahu, lalu turunkan 1 piksel ke bawah (tekan panah bawah). Lebarkan pinggang 1 piksel.
Karakter kini memiliki efek bernapas naik-turun.
Animation 1: WALK (Melangkah) FPS: 8 (Loop)
Tujuan: Siklus 4-frame berjalan/berlari.

Frame 1: Kaki kiri maju ke depan menapak, kaki kanan tertekuk ke belakang. Tangan kanan mengayun ke depan.
Frame 2: Posisi transisi; badan naik 1 piksel saat kaki kanan melangkah melewati kaki kiri.
Frame 3: Kaki kanan maju menapak di depan, kaki kiri di belakang. Tangan kiri mengayun ke depan.
Frame 4: Posisi transisi kedua; kaki kiri melangkah maju kembali ke posisi awal.
Animation 2: JUMP (Melayang) FPS: 4
Tujuan: Pose saat berada di udara.

Frame 1 (Melonjak): Kaki sedikit menekuk ke dada, tangan mengarah ke atas, pandangan menengadah.
Frame 2 (Melayang Turun): Kaki lurus mengarah ke tanah bersiap mendarat, rambut/pakaian sedikit terangkat karena gravitasi.
💾 Cara Menyimpan ke GDevelop: Setelah selesai membuat frame, klik tombol Save to GDevelop di pojok kanan atas Piskel. Di editor objek karakter, beri nama atau indeks animasi: 0 (Idle), 1 (Walk - aktifkan Loop), dan 2 (Jump).

Logika Event State Animasi & Arah Hadap (Flip)

Setelah frame selesai di Piskel, kita memprogram GDevelop agar otomatis mengganti animasi sesuai pergerakan pemain dan membalik arah hadap karakter.

A. Membalik Arah Hadap (Flip Horizontally)

Di Piskel karakter cukup digambar menghadap kanan. Saat pemain menekan tombol panah kiri, kita balik sprite menggunakan aksi Flip horizontally:

Event Membalik Arah Karakter
Condition (Syarat)
Left key is pressed
Action (Aksi)
Flip horizontally the object player: yes
Condition (Syarat)
Right key is pressed
Action (Aksi)
Flip horizontally the object player: no

B. Logika Pergantian Animasi Berdasarkan Status Fisika

Event Transisi Animasi Player
Condition (Melompat / Di Udara)
player is jumping OR player is falling
Action
Change the animation of player: set to 2
Condition (Melangkah di Tanah)
player is on floor
player is moving
Action
Change the animation of player: set to 1
Condition (Diam di Tanah)
player is on floor
player is moving (Inverted: Tidak Bergerak)
Action
Change the animation of player: set to 0

5

Penerapan Fisika & Behavior Objek

Behavior menyematkan simulasi fisika platformer ke dalam objek secara instan tanpa perlu coding matematika manual.

1. Objek Pijakan (ground)

Buka objek ground > tab Behaviors > tambahkan Platform (Type: Platform). Objek ini berfungsi sebagai alas padat yang dapat dipijak.

2. Objek Karakter Pemain (player)

Tambahkan behavior Platformer Character dan pastikan opsi Default controls: Enabled. Pemain otomatis bisa melangkah dengan tombol panah dan melompat dengan Space. Atur parameter: Gravity = 1000, Max speed = 250, Jump speed = 600.

3. Objek Musuh (enemy)

Tambahkan behavior Platformer Character, lalu HILANGKAN centang Default controls (Disabled). Turunkan nilai Max speed ke 100 agar musuh tidak melaju terlalu kencang namun tetap mematuhi gravitasi panggung.

7

Mekanik Koin, Variabel Skor & Antarmuka UI Layer

Koin yang disentuh pemain akan dihapus, menambah variabel skor tingkat scene sebesar +50 poin, dan memperbarui teks tampilan skor pada layer khusus.

Penataan Layer UI:

  1. Pada editor scene, buka panel Layers > tambahkan layer baru bernama UI di atas Base layer.
  2. Pindahkan objek scoreText ke layer UI di posisi sudut kanan atas (koordinat: X: 1121, Y: 19).
Event Pengambilan Koin
Condition (Syarat)
player is in collision with coin
Action (Aksi)
1. Delete coin
2. Change the variable skor: add 50
3. Change the text of scoreText: set to "Skor : " + ToString(Variable(skor))
4. Play the sound coin.wav (volume: 80)

8

Sistem Nyawa (Health System) & Periode Kebal

Agar game edukasi lebih ramah bagi peserta didik, pemain tidak langsung kalah saat terkena rintangan, melainkan dibekali 3 nyawa dan masa kebal sementara (*invulnerability period*).

Langkah Penyiapan Nyawa:

  • Buat variabel scene bernama nyawa dengan nilai awal 3.
  • Tempatkan 3 ikon hati (heart1, heart2, heart3) di layer UI pada pojok kiri atas layar.
Event Pengurangan Nyawa & Periode Kebal
Condition
(player is in collision with enemy OR player is in collision with hazard)
+ The timer "invincible" of player > 1.5 seconds (atau belum aktif)
Action
1. Change the variable nyawa: subtract 1
2. Start (or reset) timer "invincible" of player
3. Play the sound hurt.wav
Condition (Update Tampilan Hati)
The variable nyawa = 2
Action
Hide heart3
Condition
The variable nyawa = 1
Action
Hide heart2
Condition (Game Over)
The variable nyawa <= 0 OR player is in collision with deadZone
Action
Change to scene "gameOver"

9

Elemen Edukasi Interaktif: Kotak Kuis & Soal

Kuis interaktif adalah pembeda utama antara game platformer biasa dan game edukasi. Saat pemain menyentuh balok kuis (questionBlock), permainan memunculkan dialog soal materi pelajaran.

Elemen Kotak Dialog Soal (Layer UI):

  • quizPanel: Latar belakang kotak dialog transparan.
  • questionText: Menampilkan pertanyaan (misal: "Berapakah hasil dari 7 x 8?").
  • btnAnswerA, btnAnswerB, btnAnswerC: Tombol pilihan ganda (A: 54, B: 56, C: 64).
Event Munculnya Kuis
Condition
player is in collision with questionBlock
The variable active of questionBlock = 1
Action
1. Show quizPanel, questionText, btnAnswerA, btnAnswerB, btnAnswerC
2. Pause behavior Platformer Character of player
3. Change the variable active of questionBlock: set to 0
Condition (Jawaban Benar - Klik Tombol B)
Cursor/touch is on btnAnswerB
Mouse button was released
Action
1. Hide quizPanel, questionText, btnAnswerA, btnAnswerB, btnAnswerC
2. Resume behavior Platformer Character of player
3. Change the variable skor: add 100
4. Change the animation of questionBlock: set to 1 (berubah menjadi balok batu nonaktif)
5. Play the sound correct.wav
Condition (Jawaban Salah - Klik Tombol A atau C)
(Cursor/touch is on btnAnswerA OR btnAnswerC)
Mouse button was released
Action
1. Show alertText (isi teks: "Jawaban kurang tepat! Coba lagi.")
2. Play the sound wrong.wav

Action

2. Hide alertText

The variable skor >= 100

Show finishDoor

player is in collision with finishDoor

player is in collision with finishDoor

Implementasi Efek Suara (SFX) & Musik Latar (BGM)

Efek suara dan musik memberikan sentuhan kepuasan interaktif (*game feel*) yang memotivasi siswa untuk terus belajar.

Rancangan Tata Suara Game:

  • Musik Latar (bgm.mp3): Diputar di awal panggung secara berulang (*loop*) pada volume sedang (30%) agar tidak memekakkan telinga.
  • Suara Lompat (jump.wav): Diputar saat player is jumping (gunakan sub-kondisi Trigger once while true).
  • Suara Koin (coin.wav): Diputar saat menyentuh koin.
  • Suara Kuis Benar (correct.wav): Nada merdu penanda prestasi saat siswa menjawab benar.
  • Suara Terluka (hurt.wav): Peringatan saat menabrak rintangan atau musuh.

13

Perancangan Layar Menu: Menu Utama & Game Over

Game edukasi yang sempurna memiliki struktur transisi scene yang jelas agar siswa dapat memulai, mengulang, atau melihat capaian belajarnya.

Struktur 4 Scene Utama:

  1. Scene mainMenu: Memuat logo/judul game edukasi, tombol Mulai Belajar (memuat level1), dan tombol Petunjuk Kontrol.
  2. Scene level1 & level2: Panggung gameplay dan kuis materi pelajaran.
  3. Scene gameOver: Muncul saat nyawa habis. Berisi teks penyemangat (*"Jangan Menyerah! Kamu Pasti Bisa"*), skor terakhir, dan tombol Coba Lagi.
  4. Scene victory: Layar kemenangan setelah menyelesaikan seluruh level. Menampilkan total skor akhir, bintang apresiasi, dan tombol Kembali ke Menu.

14

Ekspor & Distribusi Game (Web HTML5, Desktop, Android)

Setelah game siap, distribusikan game kepada siswa menggunakan fitur ekspor bawaan GDevelop.

Pilihan Distribusi:

  • Web (HTML5 folder) - Paling Direkomendasikan: Klik File > Export > pilih Web (HTML5). Berkas web dapat diunggah gratis ke platform seperti Itch.io atau web sekolah. Siswa dapat langsung memainkannya di browser laptop maupun HP tanpa instalasi.
  • Aplikasi Desktop: Ekspor menjadi file mandiri .exe untuk Windows atau berkas Mac/Linux.
  • Android APK: Gunakan GDevelop Cloud Build untuk menghasilkan berkas installer APK yang dapat dipasang di tablet atau smartphone Android siswa.
